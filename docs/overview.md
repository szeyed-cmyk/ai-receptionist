# Overview

FrontDesk AI is a web app for clinics, salons, and service businesses.

## Modules

- Chat — customer web chat
- Booking — 60-minute appointments with hours, holidays, overlap, and duplicate-phone checks
- Knowledge — FAQ entries used by the AI
- Admin — dashboard, conversations, appointments, settings, password change

## Database

SQLite. Tables are created automatically. See `database/schema.sql` for the structure.
